# Restrofe

Restrofe is a mobile-first food ordering app built with Expo and React Native. It brings restaurant discovery, menu browsing, cart management, checkout, and order tracking together in one app, with supporting features for saved places, addresses, offers, payments, and a wallet.

The project currently uses local sample restaurant and dish data. Cart, order, and account-related app state is managed in a shared context and persisted locally on the device. Authentication is disabled during development.

## Features

- Browse restaurants and food categories from the home screen
- Search restaurants and dishes
- View restaurant menus and add items to a shared cart
- Apply coupons and choose an address and payment method at checkout
- Place orders and view order history and details
- Save favourite restaurants and manage addresses
- View offers, notifications, and wallet activity
- Use Expo Router for file-based navigation across iOS, Android, and web

## Tech stack

- Expo SDK 57
- React Native 0.86
- React 19
- TypeScript 6
- Expo Router
- AsyncStorage for local persistence

## Getting started

Install dependencies:

```bash
npm install
```

Start the Expo development server:

```bash
npx expo start
```

From the Expo CLI, open the app in a development build, Android emulator, iOS simulator, or web browser. Native development builds are needed for native modules that are not included in Expo Go.

## Useful commands

```bash
npx expo start       # Start the development server
npx expo start --web # Run the web version
npx expo lint        # Lint the project
npx tsc --noEmit     # Check TypeScript types
```

## Project structure

```text
src/
  app/         Expo Router screens and layouts
  components/  Shared UI components
  constants/   Theme and local catalog data
  context/     Shared cart and app state
  hooks/       Theme and color-scheme hooks
assets/        Images, icons, and other bundled assets
```

## Notes

- The restaurant and dish catalog is sample data in `src/constants/catalog.ts` and can be replaced with a backend API.
- App state persistence is implemented in `src/context/cart.tsx`.
- Authentication is currently disabled with `AUTH_ENABLED = false`.
- Native `ios/` and `android/` projects are generated by Expo Continuous Native Generation and are not committed.
